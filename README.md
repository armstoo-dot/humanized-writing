# humanized-writing

An agent skill for drafting and editing posts, articles and long copy so they read like a person wrote them, not a chatbot. It covers voice, the most common AI-writing tells, a rewrite process, a five-part score, and rules specific to X posts.

Use it by dropping `SKILL.md` into your agent's skills folder.
